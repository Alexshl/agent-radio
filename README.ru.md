# agent-radio

[English](README.md) | Русский

Самостоятельно размещаемое «личное радио» для ИИ-агентов, на несколько пользователей. У каждого пользователя своя станция: музыка (ретрансляция интернет-радио,
плейлист из общей фонотеки или тишина). Когда ваш агент заканчивает работу, он отправляет короткую текстовую сводку, сервер озвучивает её и пускает в вашу
станцию, приглушая музыку. Если никто не слушает, сообщение пропускается (без озвучки и очереди) и остаётся в истории. Агент может отправить и готовое аудио
(сведённый микс, пример голоса): оно играет при полностью выключенной музыке.

## Как это работает

```
 агенты (Claude Code, скрипты)                       слушатели
   agent-radio say / play                       телефон (VLC), браузер, любой плеер
            |                                              ^
            v  HTTPS + API-ключ                            | /stream/<id>.mp3?k=<токен>
   +--------------------+  текст   +-----------+   +-------------+
   | app (Hono + SQLite)|--------->|    TTS    |   |   Icecast   |
   | веб-интерфейс, API,|  клип    | azure /   |   | точка на    |
   | вход, фонотека,    |<---------| openai /  |   | каждую      |
   | история            |          | gemini /  |   | станцию     |
   +--------------------+          | piper     |   +------^------+
            | управление           +-----------+          |
            v                                             |
   +--------------------+  очередь голоса (музыка тише)   |
   |     Liquidsoap     |  очередь файлов (музыка выкл.) -+
   | станция на каждого |  музыка: ретрансляция | плейлист | тишина
   +--------------------+
```

- **Агенты** обращаются к `/api/say` и `/api/play` с ключом на каждый компьютер (или используют команду `agent-radio` и скилл Claude из `client/`).
- **TTS**: Azure Neural, OpenAI, Gemini или Piper (офлайн, по умолчанию и как запасной вариант). Ключи хранятся зашифрованными (AES-GCM).
- **Liquidsoap** микширует станции, **Icecast** раздаёт звук, приложение отдаёт поток по секретному токену пользователя.
- **Веб-интерфейс** (React): управление станцией, фонотека и плейлисты, ключи агентов, история, админка. Тексты интерфейса: `src/client/i18n`.

## Быстрый старт

Нужен Docker. Или скажите своему ИИ-агенту: «возьми этот репозиторий и установи радио» (его ведут [INSTALL.md](INSTALL.md) и `skills/agent-radio-setup`).

```sh
cp .env.example .env     # ADMIN_EMAIL, ADMIN_PASSWORD (12+ символов), MUSIC_DIR, PUBLIC_URL, пароли icecast
docker compose up -d --build
```

Откройте `http://localhost:8791`, войдите, на странице **Подключить агента** создайте ключ и вставьте промпт в Claude на нужном компьютере
(он выполнит `curl -fsSL <ваш сервер>/client/install.sh | sh`). Для доступа с телефона используйте Cloudflare Tunnel или Tailscale (см. INSTALL.md) и задайте
`PUBLIC_URL`. Слушайте через VLC (играет с выключенным экраном); браузеры играют только на переднем плане.

```sh
agent-radio status                      # слушатели и язык, на котором писать сводку
agent-radio say "Сборка готова, тесты проходят"
agent-radio play mix.mp3 "Вот новый микс"
```

## Справочник API

Для агентов: заголовок `Authorization: Bearer ar_...` (ключи создаются в веб-интерфейсе). Ошибки: `{"error": "<код>", "message": "..."}`.

### `POST /api/say`

```sh
curl -H "Authorization: Bearer $KEY" -H 'Content-Type: application/json' \
     -d '{"session":"invoa","host":"devbox","text":"Миграция готова"}' $URL/api/say
```
`text` до 2000 символов. Ответ `{"status":"aired"|"skipped","listeners":N}`. Если никто не слушает: `skipped`, без озвучки. Лимиты: 10 в минуту на ключ и часовой
лимит администратора на пользователя (`429`). Если включено «Называть сессию», клип начинается словами «Сесія <имя>.» на языке пользователя.

### `POST /api/play` (multipart/form-data)

```sh
curl -H "Authorization: Bearer $KEY" -F file=@mix.mp3 -F title="Микс 3" -F intro="Вот новый микс" -F session=tu-mani $URL/api/play
```
Поля: `file` (mp3, wav, flac, ogg, opus, m4a, aac; по умолчанию до 95 МБ (меньше лимита запроса Cloudflare в 100 МБ) и 20 минут, настройки админа), `title`, `intro` (проговаривается перед файлом), `session`, `host`.
Файл проверяется ffprobe, нормализуется примерно до -14 LUFS и кодируется в mp3 192k, 44,1 кГц, стерео. Он всегда сохраняется в истории (7 дней) и выходит в эфир,
только если сейчас кто-то слушает; пока он играет, музыка выключена, а голосовые сообщения ждут. Ответ `{"status","listeners","id","title","durationSec"}`;
ошибки: `400 file_required|no_audio`, `413 too_large|too_long`, `415 unsupported_type`.

### `GET /api/status`

`{"up","listeners","title","lang","speakSession","chime","voice","station":{...}}`. `lang` (`uk`, `ru`, `en`) — язык, на котором нужно писать сводки.

### `PUT /api/station/source`

`{"type":"relay","url":"https://..."}`, `{"type":"playlist","dir":"Jazz"}`, `{"type":"userplaylist","playlistId":"..."}` или `{"type":"silence"}`; применяется сразу.

### Потоки

`GET /stream/<stationId>.mp3?k=<listenToken>` и `.m3u`. Неверный токен даёт 404. «Сменить ссылку» в интерфейсе создаёт новый токен.

## Деплой без обрыва слушателей

Движок (Liquidsoap) и Icecast держат соединения всех слушателей: их перезапуск обрывает все плееры. Изменения приложения выкатывайте только командой
`docker compose up -d --build app`; `liquidsoap`/`icecast` трогайте, только если изменился `liquidsoap/radio.liq` или их образ, и предупреждайте об этом.
Веб-плеер переподключается сам (1 с, 2 с, 5 с, затем каждые 10 с около 5 минут, а также при возврате на вкладку и появлении сети);
VLC и другие плееры обычно нет: слушателям нужно снова нажать play. Тома `data` / `shared` не удалять (`down -v` только для dev-стенда).

### Локальные нейро-голоса (необязательный сервис)

`tts-local`: Python 3.11 на CPU (видеокарта AMD gfx803 не поддерживается ROCm / PyTorch), внутренний HTTP API (`GET /voices`, `POST /synthesize`).
Включается так: `COMPOSE_PROFILES=local-tts` в `.env` и `docker compose up -d --build tts-local`. Первый запуск скачивает несколько ГБ моделей в том `ttsmodels`.
Движки: `styletts2` (украинский, MIT), `silero` (русский, **CC BY-NC-SA 4.0, только некоммерческое использование**), `f5` (русский, экспериментальный, `TTS_LOCAL_F5=1`,
на CPU очень медленный). Включение для пользователей: Админка > Голос и TTS > «Локальные нейро-голоса». Если синтез дольше 15 с, `POST /api/say` отвечает
`202 queued`, и сообщение выйдет в эфир, когда будет готово (если слушатели ещё есть). Подробности и результаты замеров: README.md.

## Безопасность

- Аккаунты только по приглашению; пароли PBKDF2-SHA256; сессионная cookie httpOnly SameSite=Lax (Secure за https); проверка Origin для каждого изменяющего запроса
  с cookie; ограничение попыток входа по IP и почте. API-ключи и ссылки-приглашения хранятся в виде хешей. Ключи провайдеров шифруются `APP_SECRET`.
- По умолчанию приложение слушает только 127.0.0.1; TLS обеспечивает туннель (Cloudflare Tunnel, Tailscale). Не открывайте порт приложения в интернет напрямую.
- Ссылки на потоки (пресеты и свои ссылки) загружает приложение, а не движок: движок работает в docker-сети без выхода в интернет. Приложение принимает только
  публичные адреса (проверяется каждый ответ DNS, соединение привязано к проверенному адресу, редиректы проверяются заново) и передаёт звук движку по внутреннему
  порту, который не публикуется.
- Об уязвимостях сообщайте приватно через GitHub Security Advisories (вкладка Security → «Report a vulnerability»).
